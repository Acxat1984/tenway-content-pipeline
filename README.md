# tenway-content-pipeline

Контент-конвейер: Claude пишет сценарии → GitHub Actions рендерит вертикальное видео (озвучка, демо-скринкаст Playwright, сборка ffmpeg) → готовый ролик прилетает в Telegram.

Русские ролики читаются своим голосом, английские — синтезом Fish Audio. Почему так — в `content-plan.md`.

## Как это работает

1. Claude (Cowork) кладёт сценарий в `jobs/*.json` со статусом `approved`
2. Для русского ролика (`"voice": "self"`) вы начитываете сегменты в `voice/<id>/` — что читать, лежит там же в `README.md`
3. Push запускает workflow `build-videos`
4. Воркер: озвучка по сегментам → запись скринкаста с таймингом по озвучке → субтитры → mp4 1080×1920
5. Ролик + текст поста отправляются в Telegram-бот, `out/<id>/status.md` коммитится обратно как журнал

## Секреты (Settings → Secrets and variables → Actions)

- `FISH_API_KEY` — ключ Fish Audio
- `TG_BOT_TOKEN` — токен Telegram-бота
- `TG_CHAT_ID` — (опционально) chat_id; если не задан, определяется по последнему сообщению боту

## Формат задания

См. `jobs/2026-08-25-chatgpt-3-fishki.json`: `segments[].text` — текст озвучки и субтитров, `segments[].scene` — что происходит на экране (`title` / `user` / `ai` / `outro`).

- `"voice": "self"` — читаете вы, файлы берутся из `voice/<id>/segNN.*` (любой формат: m4a, ogg, mp3, wav). Тишина по краям режется, громкость выравнивается, тайминг скринкаста подстраивается под вашу речь.
- `"voice": "<reference_id>"` — синтез Fish Audio. Для английских роликов.
- Знак `+` перед гласной в тексте — ударение для синтеза. В субтитры и в лист для записи не попадает; сборка предупредит, если плюс стоит не на гласной.

## Прослушки и проверки

Отдельные workflow, запускаются вручную и шлют образцы в Telegram:

| workflow | зачем |
|---|---|
| `voice-audition` | перебрать голоса Fish |
| `stress-probe` | какую разметку ударения движок вообще читает |
| `tts-compare` | сравнить движки (Silero без ключа; остальные — по секрету) |
| `silero-tune` | латиница и темп речи |
| `selftest` | тракт озвучки и чистота словаря, без внешних отправок |

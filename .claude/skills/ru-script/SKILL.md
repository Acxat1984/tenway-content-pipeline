# Русский текст для озвучки

Текст ролика пишется не для чтения глазами, а для произнесения вслух и восприятия
на слух. Это разные языки. Грамматически безупречная фраза может быть
непроизносимой, а «неправильная» разговорная — звучать идеально.

Главная проверка одна: **прочитайте вслух**. Если запнулись, если не хватило
дыхания, если захотелось переставить слова — текст плохой, независимо от того,
как он выглядит на экране.

## Устная речь против письменной

Письменный текст экономит место, устный — дыхание. В письменном ценится
плотность, в устном — воздух.

| письменно (плохо для озвучки) | устно (хорошо) |
|---|---|
| Отвечаю по своим тратам | Расскажу, сколько плачу сам |
| Сервисы дают рабочий лимит | Бесплатного хватает надолго |
| Это закрывается здесь | Этого хватит |
| Деньги появляются, когда вы автоматизируете процесс | Платить начинаешь, когда ставишь это на поток |
| Не ищите руки под задачу | Не нанимайте человека на то, |
| Разница огромная | И вот это — совсем другая история |

**Признаки письменной речи, которые надо вычищать:**

- Отглагольные существительные: *«сокращение найма»* → *«их перестали нанимать»*.
- Цепочки родительных падежей: *«снижение стоимости обработки заявки»* →
  *«обрабатывать заявку стало дешевле»*.
- Причастные и деепричастные обороты: *«получив ответ, вы увидите»* →
  *«ответ придёт — и вы увидите»*.
- Пассив: *«счёт отправляется в бухгалтерию»* → *«счёт уходит в бухгалтерию»*.
- Книжные связки: *«таким образом»*, *«при этом»*, *«однако»*, *«в свою очередь»*.
  Вслух они звучат как доклад. Замена: *«и вот»*, *«а»*, *«но»*, *«зато»*, пауза.
- Слова, которых никто не говорит: *«ухищрения»*, *«порог входа»*, *«внедрение»*,
  *«оптимизация»*, *«потребность»*.

## Дыхание и ритм

Один сегмент — одна мысль и один выдох. Ориентир: **12–18 слов**, 5–8 секунд.

- Внутри сегмента не больше одной запятой. Две — уже трудно читать.
- Длинное предложение рубите на два коротких. Точка — это вдох.
- Числительные пишите словами так, как их произносят: *«девятнадцать процентов»*,
  *«двадцать долларов»*. Цифрами — только на экране.
- Не ставьте подряд два слова на стыке одинаковых согласных: *«факт того»*,
  *«риск случая»*. Язык спотыкается.

Ритм должен меняться. Три одинаковых по длине сегмента подряд усыпляют. После
двух длинных дайте короткий в три слова — он и будет услышан.

## Англицизмы

Правило простое: **есть живое русское слово — берём его. Нет — берём англицизм,
но не кальку.**

| не так | так | почему |
|---|---|---|
| фича | возможность, штука | «фича» вслух звучит жаргоном |
| кейс | случай, пример, история | «кейс» — калька, в речи мешает |
| таск | задача | |
| юзать | пользоваться | |
| зарелизить | выпустить | |
| перформанс | скорость, отдача | |
| челлендж | сложность, вызов | |
| инсайт | наблюдение, вывод | |
| скилл | навык | |
| промпт | промпт | прижилось, замены нет |
| нейросеть | нейросеть | лучше, чем «модель» или «ИИ» |
| подписка | подписка | обычное слово |

**Названия читаются кириллицей, как произносятся:** чат джи-пи-ти, клод, джемини,
мидджорни, эйч-эн, си-ар-эм. Латиница в текст сегмента не попадает никогда —
русская озвучка её проглотит, а живой человек прочтёт неуверенно.

Не переводите насильно то, что прижилось. *«Промпт»* понятнее, чем
*«текстовый запрос к языковой модели»*. Цель — понятность, а не чистота.

## Структура: рассказ, а не презентация

Частая ошибка — писать ролик как слайды: «три уровня», «четыре пункта»,
«во-первых, во-вторых». На бумаге это структура, на слух — список без сюжета,
и его не досматривают.

Работает движение от человека к решению:

1. **Факт или боль.** Конкретная вещь, которую можно потрогать. Не «поговорим
   о ценах», а «мне выставили счёт на сто тридцать тысяч».
2. **Поворот.** «Но главное не в этом» — то, чего зритель не ожидал. Здесь
   удерживается внимание на середине, где обычно уходят.
3. **Объяснение.** Почему так, коротко и на примере.
4. **Что делать.** Конкретное действие сегодня, а не «следите за трендами».
5. **Вопрос.** Такой, на который есть что ответить из своего опыта.

Внутри — говорите с одним человеком, а не с аудиторией. «Вы» в единственном
числе, «ты» — если так принято на канале. Никаких «друзья», «ребята», «всем
привет».

## Что проверить перед записью

- Прочитайте вслух целиком, не останавливаясь. Где запнулись — там правка.
- Хватило ли дыхания на каждый сегмент?
- Есть ли хоть одно слово, которое вы не сказали бы в разговоре за столом?
- Первая фраза называет конкретную вещь или только объявляет тему?
- В середине есть поворот — или всё едет ровно и предсказуемо?
- Латиница в текстах сегментов: её быть не должно.
- Числительные — словами.

## Как править чужой или свой старый текст

Не редактируйте по фразе — перепишите заново, глядя только на смысл. Правка
письменного текста «под устный» почти всегда оставляет исходный синтаксис,
и он продолжает звучать казённо. Быстрее пересказать своими словами вслух,
записать как получилось, и уже это причесать.
